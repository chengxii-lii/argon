Ctrl+T opens a command palette right on the page you're on.

Set Ctrl+T (and Ctrl+W)

Browsers don't let an extension take Ctrl+T on its own, so it's one quick step:

  1. Open the shortcuts page with the button below.
  2. Find argon → “Open the palette”, click the pencil and press Ctrl T.
  3. Optional: “Close tab, but never your last one” → Ctrl W. Closing your last tab then lands on argon’s new tab instead of quitting Helium.

If another extension already uses a shortcut, clear it there first.
